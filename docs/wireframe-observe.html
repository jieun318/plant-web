식물집사 · 관찰 중심으로 바꾼 구조

교수님 피드백 "기능이 이것저것 많다, 주가 뭐냐"를 반영했습니다. 기존에 만든 판별·진단은 지우지 않고, 관찰을 위한 한 단계로 자리를 옮겼습니다.

주가 뭐냐고 물으면 라즈베리파이가 식물 옆에서 매일 사진과 온습도를 기록하고, AI가 그걸 보고 관찰일지를 써준다.

바뀐 점

주가 되는 것

  • 오늘 — 내 식물들의 오늘 상태를 한눈에. 첫 화면입니다
  • 관찰일지 — 날짜별 사진 + 온습도 + AI 코멘트. 이 프로젝트의 중심 화면
  • AI 관찰 코멘트 — 매일 사진과 온습도를 Gemini 에 보내 한두 문장으로 요약
  • 상태는 세 단계로만: 좋음 / 주의 / 확인 필요

자리를 옮긴 것

  • 판별 → 식물 추가 1단계. 적정 온습도 기준을 정하는 용도
  • 진단 → 관찰일지 아래 보조 버튼. 기기 없는 식물을 위해 남김
  • 가이드 → 관찰일지 아래 보조 버튼
  • 물 줬어요 → 보조 버튼. 관찰일지에 기록으로 함께 쌓임
  • 코드는 지우지 않습니다. 메뉴에서만 뺍니다

새로 만들 것

  • 기기 API — 온습도, 사진 받기 (기기별 토큰)
  • 매일 관찰 코멘트 생성 — 하루 1회, 오전 10시 사진 기준
  • 오늘 / 관찰일지 화면
  • 식물 추가 3단계 흐름 (기존 판별·등록을 이어 붙임)
  • 라즈베리파이 파이썬 — 사진과 온습도를 보내기만
