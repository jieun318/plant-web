# 기능요구사양서

**프로젝트명** 식물집사 — AI 식물 관찰일지 웹서비스
**팀 구성** 3인
**플랫폼** PC / 모바일 웹 + 라즈베리파이 관찰 기기

**한 줄 소개** 라즈베리파이가 식물 옆에서 매일 사진과 온습도를 기록하고, AI가 그걸 보고 관찰일지를 써준다.

**입력** 마우스 클릭, 터치, 사진 업로드, 카메라 자동 촬영, 온습도 센서
**출력** LCD (웹 브라우저 화면)

---

## 1. 제공 기능

| 순번 | 기능 내용 |
|---|---|
| 1 | 식물 사진을 업로드하거나 촬영하면 시스템이 종을 판별한다. |
| 2 | 판별된 종의 적정 온도·습도 범위가 해당 식물의 관찰 기준으로 저장된다. |
| 3 | 별칭과 두는 곳을 지정하여 식물을 등록한다. |
| 4 | 등록한 식물에 관찰 기기를 연결하면 기기별 인증 코드가 발급된다. |
| 5 | 기기가 온도와 습도를 10분 간격으로 측정하여 서버에 전송한다. |
| 6 | 기기의 카메라가 매일 정해진 시각에 식물을 자동 촬영하여 서버에 전송한다. |
| 7 | 측정된 온습도가 적정 범위를 벗어나면 식물 상태가 "주의" 또는 "확인 필요"로 표시된다. |
| 8 | AI가 하루 1회, 당일 사진과 이전 사진, 하루 온습도를 비교하여 관찰 코멘트를 작성한다. |
| 9 | 관찰일지에서 날짜별 사진, 평균 온습도, AI 코멘트가 시간순으로 조회된다. |
| 10 | 최근 7일 온습도 변화가 적정 범위와 함께 그래프로 출력된다. |
| 11 | 첫 화면에서 모든 식물의 오늘 사진, 온습도, 상태, AI 코멘트가 한눈에 출력된다. |
| 12 | 기기가 1시간 이상 기록을 보내지 않으면 "연결 끊김"으로 표시된다. |
| 13 | 기기가 없는 식물도 사용자가 직접 사진을 올려 진단하고 관리 가이드를 볼 수 있다. (보조 기능) |

## 2. 동작에 필요한 환경

| 순번 | 필요 환경 |
|---|---|
| 1 | 인터넷 연결 (필수) — 웹 서비스와 관찰 기기 모두 필요 |
| 2 | 경진대회장 네트워크 미제공 → 휴대폰 테더링 필요. **관찰 기기도 같은 테더링에 연결**해야 함 |
| 3 | Google Gemini API 키 — 종 판별 및 관찰 코멘트 생성. AI Studio 무료 발급 |
| 4 | Supabase — 데이터베이스, 사용자 인증, 사진 저장 |
| 5 | Vercel — 웹 서비스 배포. 기기가 24시간 데이터를 보낼 서버 주소 |
| 6 | 라즈베리파이 — 관찰 기기 본체, 상시 전원 연결 |
| 7 | 라즈베리파이 카메라 모듈 — 자동 촬영. 보드 모델에 맞는 리본 케이블 필요 |
| 8 | 온습도 센서 DHT11 — 온도 0~50°C (±2°C), 습도 20~90% (±5%), 분해능 1 단위. 오차가 있어 하루 평균과 연속 일수로 상태를 판정 |
| 9 | 카메라 거치대 — 매일 같은 각도로 촬영해야 사진 비교가 가능 |
| 10 | 사용자 단말 — PC 또는 스마트폰 브라우저 |

## 3. UI 화면 (LCD)

**입력** 마우스 클릭 / 터치 · **출력** 웹 브라우저 화면
**설계 기준** 데스크톱 가로 레이아웃, 모바일에서는 1단으로 접힘

### 3.1 메뉴 구조

```
상단 네비게이션
│
├─ 오늘 (S-01)                    ← 첫 화면
│   └─ 식물 카드 → 관찰일지 (S-02)
│
├─ 관찰일지 (S-02)                ← 중심 화면
│   ├─ 식물 수정 (S-04)
│   └─ 보조 기능
│       ├─ 직접 진단 (S-05)
│       └─ 관리 가이드 (S-06)
│
├─ 식물 추가 (S-03)
│   ├─ 1단계 사진으로 알아보기
│   ├─ 2단계 등록
│   └─ 3단계 기기 연결
│
└─ 우상단 계정 버튼 → 계정 (S-07)
```

### 3.2 화면별 구성

| ID | 화면명 | 화면 구성 | 입력 | 출력 |
|---|---|---|---|---|
| S-01 | 오늘 | 상태 요약(관찰 중·확인 필요·미연결), 식물 카드 그리드 | 카드 클릭 | 식물별 오늘 사진, 온습도, 상태, AI 코멘트 |
| S-02 | 관찰일지 | 오늘 사진, 날짜별 사진 띠, 현재 온습도, 7일 그래프, 일지 목록, 보조 버튼 | 날짜·사진 클릭 | 온습도(적정 범위 대비), 그래프, 날짜별 AI 코멘트 |
| S-03 | 식물 추가 | 3단계 진행 표시 — 사진 판별 / 별칭·두는 곳 입력 / 기기 인증 코드 | 사진 업로드, 입력, 버튼 클릭 | 종명, 적정 온습도 기준, 인증 코드 |
| S-04 | 식물 수정 | 별칭, 두는 곳, 기기 연결 해제, 삭제 | 입력, 버튼 클릭 | 수정된 정보 |
| S-05 | 직접 진단 | 증상 사진 업로드, 문답(최대 3회), 결과 | 사진, 선택지 클릭 | 원인, 판단 근거, 조치사항 |
| S-06 | 관리 가이드 | 탭 4개(물주기·빛·분갈이·비료) | 탭 클릭 | 항목별 관리법 |
| S-07 | 계정 | 계정 정보, 서비스 정보 | 버튼 클릭 | 등록 식물 수, 기기 수 |

### 3.3 상태 판정 기준

| 상태 | 조건 |
|---|---|
| 좋음 | 하루 평균 온습도가 적정 범위 안 |
| 주의 | 적정 범위를 벗어난 날이 1~2일 |
| 확인 필요 | 3일 이상 연속으로 벗어남, 또는 AI 코멘트에서 잎 변화가 감지됨 |
| 연결 끊김 | 기기 기록이 1시간 이상 없음 |
